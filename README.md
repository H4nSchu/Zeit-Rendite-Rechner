# Zeit-Rendite-Rechner

Eine interaktive Single-Page-App (React), um den Effekt von Zinseszins auf deine **wöchentliche Arbeitszeit** zu visualisieren. 

## Idee
Dieses Tool rechnet dein angespartes Kapital und deine monatlichen Sparraten nicht nur in Euro um, sondern zeigt dir direkt den Gegenwert in **Freizeit** an. 
Es zeigt dir exakt, wie viele Stunden, Minuten und Sekunden Arbeitszeit du dir pro Woche durch dein passives Einkommen „freikaufst“.

## Features
- **Getrennte Renditen:** Simulation von Anspar-Rendite (Wachstumsphase) und Entnahme-Rendite (Sichere Entnahmerate).
- **Schneeball-Dashboard:** Eine detaillierte Matrix, die zeigt, wie viel Arbeitszeit dir der Zuwachs des aktuellen Jahres, Monats, der Woche und sogar eines einzelnen Arbeitstages für immer erspart.
- **Ziel-Kalkulator:** Berechnet auf das Jahr genau, wann du dein gewünschtes Teilzeit-Pensum (z. B. 20h-Woche) erreicht hast.
- **Dynamische Diagramme:** Visualisiert mit Chart.js, wie der Zinseszinseffekt über die nächsten 25 Jahre arbeitet.

## Technik
- 100% Client-Side. Keine Server, keine Datenbanken.
- React via CDN.
- Tailwind CSS via CDN.
- Chart.js zur Datenvisualisierung.
